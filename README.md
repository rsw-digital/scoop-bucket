# RSW Digital Scoop bucket

Official [Scoop](https://scoop.sh) bucket for apps by RSW Digital Ltd.

```powershell
scoop bucket add rsw-digital https://github.com/rsw-digital/scoop-bucket
scoop install rsw-digital/screenmarkup
```

| App | Description |
|---|---|
| [Screen Markup](https://screenmarkup.com) | Draw on your phone or tablet and see it live on your Windows PC screen. Free 7-day trial. |
